Quest VRChat Tool

WindowsでQuestの写真・ログをかんたん転送

Meta Quest と Windows をつなぎ、VRChat の写真ファイルやログをPCへインポート・保存・管理するための専用ツールです。操作は3ステップで完了します。

対応機能

VRChat 写真のインポート

Quest内のVRChat写真をPCに転送し、分かりやすい名前で保存します。オフラインでも画像を確認できます。

ログの取得とマージ

Quest内のVRChatログを取り出し、既存のPCログへ追記（マージ）します。デバッグ情報の調査や保存に便利です。

ADB接続の確認

Questの接続状態をチェックし、USBデバッグが正常に有効になっているか確認します。接続トラブル時の原因特定に役立ちます。

保存先と設定の管理

保存先フォルダーを指定し、設定をファイルに保存できます。次回起動時も同じ設定を使い続けられます。

操作の流れ

  • 1. QuestをPCにUSBケーブルで接続し、Quest側でUSBデバッグを許可
  • 2. 保存先フォルダーを指定して、インポート対象を選択
  • 3. 「写真をインポート」または「ログをインポート＆マージ」を実行
ポイント：Windows Defender の SmartScreen が表示された場合は「詳細情報」から実行してください。発行元未署名のツールのため、警告が出ることがあります。

こんな方におすすめ

  • Quest内のVRChat写真をPCで管理したい
  • VRChatログをPCで分析・保管したい
  • ADB接続の状態を手軽に確認したい
  • WindowsでQuestデータをオフライン保存したい

注意事項

  • 本ツールはADB（Android Debug Bridge）を使用します。事前にADBがインストールされている必要があります。
  • QuestとPCを接続する際は、データ通信対応のUSBケーブルをご利用ください。
  • 初回接続時、Quest内でUSBデバッグ許可を求める画面が表示されます。「このPCへの接続を常に許可する」にチェックして許可してください。
