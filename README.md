## インストール方法・使い方

### 使い方
1. GitHubのReleasesページから対象のビルドを選択し、zipファイルをダウンロードします。

2. zipファイルをWindowsエクスプローラー、または7-Zip等のツールで解凍します。

3. QuestVRCTool.exeを起動します。
Windows Defender（SmartScreen）が表示された場合は、「詳細情報」→「実行」を選択してください。
※本アプリケーションは安全に配布されていますが、発行元未署名のため警告が表示される場合があります。

4. 起動後、インポート対象の項目を選択し、上部設定欄で保存先フォルダーを指定します。

5. 「インポート開始」ボタンをクリックします。

6. 実行結果はポップアップウィンドウに表示され、詳細はログウィンドウに出力されます。

### Q&A
Q.なんでWindows Smart Screnn(Windows Defender)が起動するの？
A.外部ツール・アプリケーションで発行元が確認できない場合に警告されてしまうからです。これに関しては仕様ですので無視してもらって大丈夫です。

Q.全般設定の一時フォルダーって？
A.画像・ログなどを一時的に保存してリネーム・マージを行うためのフォルダーです。必ず管理者権限が必要ない場所を選択してください、

Q.ビルドはどれ選べばいい？
A.とりあえず最新のやつを選べば大丈夫です。
ビルド番号は日付の数列で管理しているので、ご参考までに。

## 注意点
### 本システムはADBを使用しています
本ツールは、Android Debug Bridge（ADB）を使用して通信を行います。
ADBは、Android OS搭載デバイスとPC間で通信を行うためのGoogle公式ツールです。

Meta Questに搭載されているHorizon OSはAndroidベースのため、ADBによる通信が可能です。
ADBがインストールされていない場合は、Google公式のAndroid Developer Portalよりインストールしてください。

### Quest側で接続を許可してください。
初回接続時、Quest側に「本デバイスへのデバッグ接続を許可しますか？」という確認画面が表示されます。
「このPCへの接続を常に許可する」にチェックを入れ、「許可」を選択してください。

許可しない場合、Questが認識されず、インポート機能を利用できません。

### 充電状態とバッテリー残量にご注意ください
データ通信専用のUSBケーブルを使用した場合、充電速度が低下し、使用中にバッテリー残量が減少する可能性があります。
必要に応じて給電対応のケーブルをご利用ください。
